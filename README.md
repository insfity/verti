# 竖影 · Verti / Vertical Studio

[下载最新版 macOS 应用](https://github.com/insfity/verti/releases/latest) · 当前版本 **1.0.6** · Apple silicon · macOS 15+

将 2–4 张任意比例的 JPEG / HEIC 照片上下拼成竖幅图片。原生 SwiftUI + AppKit 界面，Core Image 合成，全部在本机处理。

## 运行

需要 **macOS 15.0 或更高版本**。1.0.1 起仅提供 Apple silicon（arm64）版本，不再构建 Intel 版本。双击即可启动，也可以将应用拖入“应用程序”文件夹。

当前交付为本地 ad-hoc 签名构建，未使用 Apple Developer ID 签名或公证；跨电脑传输后 macOS 可能要求确认来源。无需关闭系统安全功能。源代码可在自己的 Mac 上重新构建。

## 操作

1. 选择照片数量（2、3 或 4 张）和竖屏比例：9:16、3:4、2:3、4:5、9:21。
2. 点击“导入照片”，或点击空图片区块逐张加入。空工作区批量选择 2–4 张时会自动匹配区块数量。支持将文件拖入画布；单张拖入某区块可替换该张照片。
3. 单击选中照片。拖动时仅移动完整照片的虚线框，松开鼠标后更新图片；Esc 取消拖动。滚轮或触控板捏合缩放，缩放以指针所在位置为中心。右侧滑块也可缩放。
4. “铺满”会居中填满区块；“完整显示”保留整张照片；“居中”只重置位置。双击画布里的照片恢复铺满。聚焦画布后可用方向键微调，Shift + 方向键加快移动。
5. 左侧上下箭头调整顺序，循环箭头替换选中照片，垃圾桶移除照片。减少照片数量且会移除已导入内容时会提醒。
6. 选“无缝”“留白”或“画廊”预设，再按需调整边框、照片间隙、画框颜色和投影。投影包括浓度、柔和度和向下偏移；它绘制在照片周围的画框或间隙中。只有存在边框或间隙时才可启用投影。
7. 选择长边像素和编码质量，点击“导出图片”。完成后仅在应用内提示成功，不会打开 Finder。

画框和间隙的大小随输出分辨率等比例调整，界面显示最终输出中的像素值。照片缩小后露出的区域使用画框颜色；超出区块的内容会裁切。橙色选框和序号仅用于编辑，不会导出。

快捷键：⌘N 新建、⌘O 导入、⇧⌘E 导出。

## HDR 与 SDR

- 识别 ImageIO 可解码的 Apple HDR gain map 和 ISO gain map，输入支持 JPEG、HEIC / HEIF。
- 所有已导入照片均带可读取的 gain map，且“保留 HDR”开启时，使用 HDR 合成和 HDR 预览；填满所有区块后可导出 HDR HEIC 或 HDR JPEG。
- 任意一张输入为 SDR，整个工作区立即切换为 SDR，输出固定为 SDR JPEG。移除或替换这张 SDR 照片后，若其余输入均为 HDR 且开关开启，则恢复 HDR。
- 手动关闭 HDR 时，使用照片的 SDR 基础图像（必要时由系统做 SDR 色调映射），输出 SDR JPEG。
- HDR 导出会用合成后的 SDR 和 HDR 图像重新计算 gain map，随后检查成品中是否确有 gain map；如果生成失败，报告错误，不会把 SDR 文件冒充 HDR。
- 导出使用 Display P3 色彩配置，颜色管理由 macOS 完成。HDR 高光效果需要支持 EDR/HDR 的屏幕和查看软件，并会受到显示器亮度、可用动态范围影响。不同设备或查看器不可能保证相同的物理亮度。

预览和导出使用同一套图像变换、裁切、边框、颜色与阴影合成流程。交互预览降低分辨率以保持流畅，导出按完整尺寸重新渲染；JPEG/HEIC 为有损编码，压缩细节会受质量设置影响，因此“效果一致”指构图、颜色管理与处理流程一致，并非逐像素无损相同。

## 新建与退出

不保存工程文件、自动草稿或原片副本。导入的编码数据由内存中的图像对象持有。“新建”清空全部照片和参数；存在未导出的作品或导出后又修改过时，会弹出确认。关闭窗口、退出应用也会检查未导出的内容。导入/导出过程中会锁定修改，避免输出与当前设置错位。应用可能保存窗口位置等系统界面偏好，不保存编辑项目。

## 构建与验证

无第三方依赖。需要 macOS 15+、Swift 6.0+ 和 Apple Command Line Tools（本次使用 Swift 6.1.2 / macOS 15.5 SDK），不要求安装完整 Xcode。

在本目录运行：

```sh
./Scripts/build.sh
```

生成 `dist/竖影.app`，仅编译 arm64 并作本地签名。也可以给脚本传入输出目录，或设置 `BUILD_ROOT` 指定编译缓存目录。

运行验证：

```sh
./Scripts/verify.sh
```

检查包含：所有比例/数量组合的无缝布局、任意原图比例的适配、混合输入与 HDR 关闭后的 SDR 导出、HDR JPEG/HEIC 实际编码和重新解码、边框投影和裁切像素、预览/导出对照、不完整工作区禁止导出。测试自带断言执行器，Command Line Tools 环境不依赖 XCTest。

测试需访问本机 Core Image/图像编码服务；限制图形服务访问的命令沙箱可能让 Core Image 返回空结果。实际应用在正常 macOS 图形会话中运行。

生成仅用于测试的图片：

```sh
./Scripts/verify.sh --fixtures /absolute/path/to/fixtures/hdr
```

会在指定目录生成三张带 gain map 的合成图，并在其父目录生成一张 SDR 合成图。它们用于测试图像管线，不是实拍照片。

## 源码结构

- `Sources/VerticalCore/Composition.swift`：照片读取、布局、裁切、SDR/HDR 合成、gain map 编码和校验。
- `Sources/VerticalStudio/EditorModel.swift`：工作区状态、导入、预览队列、导出、未导出提醒。
- `Sources/VerticalStudio/CanvasView.swift`：AppKit 画布、HDR 显示、鼠标/触控板操作与拖放。
- `Sources/VerticalStudio/ContentView.swift`：中文 SwiftUI 界面。
- `Tests/VerticalCoreTests/CompositionTests.swift`：图像管线验证与测试图生成。

实现依据：Apple [Use HDR for dynamic image experiences in your app](https://developer.apple.com/videos/play/wwdc2024/10177/) 及 macOS 15 SDK 中 Core Image / ImageIO 的公开接口。HDR 导出使用 `CIImageRepresentationOption.hdrImage`，并非简单复制某张输入照片的原始 gain map。

## 1.0.1 HDR 预览修订

预览改用明确的 Display P3 PQ 编码，并从实际合成像素测量动态范围、写入 CGImage contentHeadroom。避免仅把扩展线性工作图当作显示图传给 AppKit。新增检查确认 HDR 预览具有 PQ 色彩空间和大于 1 的 headroom。7 组自动化测试通过；真实屏幕显示效果待使用原问题照片复核。

## 1.0.2 交互更新

选中照片显示完整范围虚线框，框线不受照片区块裁切遮挡。完整范围超出画布时，左下角示意图显示照片与可见区块的位置关系。拖动期间只重绘边框，鼠标松开后才提交位置并重新合成预览。虚线及示意图仅作编辑辅助，不会导出。

## 1.0.3 画布观察体验

选中区块的红色框线向外绘制，内沿与实际裁切边界重合。编辑时，未被照片完全覆盖的区块会在画布右侧显示“未填满”；拖动过程中按待提交位置判断。点击画布周围、画框留白或照片缩小后露出的空白，可取消选择并隐藏所有辅助线、序号、示意图和提示。点击照片恢复编辑。中央预览增加可用空间。

## 1.0.4 导出名称

默认命名为 `verti-yyMMdd-比例-HDR/SDR`，日期取导出时本机日期。例如 `verti-261024-9：16-HDR.heic`；比例采用全角冒号 `：`，避免 macOS 文件对话框对半角冒号的特殊处理。导出后仅更新状态栏，不再打开文件夹。

## 1.0.5 默认文件夹

成功导入（包括替换、拖入文件）后记住导入目录，下次导入默认打开该目录；此偏好跨应用重启保留，取消或失败的导入不更新它。导出默认定位到当前工作区最先成功导入那张照片的文件夹，后续排序、替换或继续导入不改变此默认位置。点击新建后重新确定首张照片的位置。目录失效时使用可用的最近导入目录或系统默认位置。仍不保存工程内容。

## 1.0.6 SDR 输入禁用 HDR 开关

任意已导入照片为 SDR 时，“保留 HDR”显示为关闭且置灰，无法操作。移除或替换全部 SDR 照片后恢复可用，并恢复此前的 HDR 开关偏好。
